# Adopt uniform labelling convention

1.  I think the problem can be solved by having uniform styling for all of our
    prompts and labels.
2.  Currently the opposite is done, where inputted values are coloured in green.
3.  I think that a subtle background colour behind the prompts and labels might
    work well.
4.  Prompts should also all end in `:`
5.  A more significant cue like "-- type here" is unnecessary.
6.  We can also drop the `(max 64 chars)` part of the prompt.
