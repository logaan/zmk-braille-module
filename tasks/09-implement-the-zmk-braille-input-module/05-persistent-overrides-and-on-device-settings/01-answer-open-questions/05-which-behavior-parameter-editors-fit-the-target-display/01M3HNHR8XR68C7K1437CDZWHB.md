# Which behavior parameter editors fit the target display?

1. Choose a compact editor approach for at least common key presses, modifier combinations, and Bluetooth profile commands as required by spec §7.2.
2. Decide which compiled behaviors can be offered with valid zero/one/two-parameter bindings; behaviors lacking a usable parameter editor may be omitted from selection.
3. Keep the underlying rule/action representation general; an editor for every behavior or a general multi-action composition UI is not required by this task.
