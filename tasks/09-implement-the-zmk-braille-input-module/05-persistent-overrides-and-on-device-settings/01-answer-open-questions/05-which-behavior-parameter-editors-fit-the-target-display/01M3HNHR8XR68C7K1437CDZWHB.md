# Which behavior parameter editors fit the target display?

1. Choose a compact editor approach covering at least common key presses, modifier combinations, and Bluetooth profile commands.
2. Decide which compiled behaviors can be offered with valid zero-, one-, or two-parameter bindings; behaviors without a usable editor may be omitted from selection.
3. Keep the underlying rule and action representation general; an editor for every behavior or a multi-action composition UI is not required.
