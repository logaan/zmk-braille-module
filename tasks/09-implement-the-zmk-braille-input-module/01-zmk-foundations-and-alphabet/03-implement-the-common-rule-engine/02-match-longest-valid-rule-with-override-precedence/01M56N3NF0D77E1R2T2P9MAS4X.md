# Matcher delivered: longest valid rule with override precedence

## 1. Implementation

1. Completed only this leaf in commit `64c0784` (`Match longest valid rule
   with override precedence`).
2. Found a prior interrupted draft of this leaf uncommitted in the worktree
   (`src/braille_engine.c`, `include/braille_engine.h`); reviewed it against
   the requirements, fixed three defects, and completed it with the missing
   unit tests.
3. `src/braille_engine.c` matches the selected character table, the mode's
   factory command table, and the user override layer through the single
   nine-bit path `braille_chord_resolved` (the chord capture completion
   hook); every table is a `struct braille_rule_table` view.
4. Matching: longest valid sequence wins; for the same input the applicable
   user override beats the factory rule; a shorter override never defeats a
   longer valid sequence. No timer: ambiguous input stays pending until the
   next chord extends it or rules it out.
5. Ruled-out input commits the longest complete match, reprocesses the
   remaining cells exactly once (an orphan tail drops with a display notice
   via the weak `braille_engine_notify_dropped_prefix` hook), and interprets
   the breaking chord from scratch. Whitespace chords (Braille space,
   Return, Tab; supplied per mode via `braille_engine_set_whitespace`)
   commit pending input with `BRAILLE_COMMIT_WORD_END` evidence then perform
   themselves; any other command chord discards pending input without host
   output then performs itself.
6. `when` predicates are tested against the context captured at the start
   of the sequence; pending cells never change it, and this leaf never
   mutates the context (class transitions arrive in phase 02).
7. `braille_engine_validate_factory` rejects conflicting factory mappings
   within a mode, including across the character and command tables;
   shorter/longer prefixes and same-cells rules with disjoint `when`
   predicates are not collisions; overrides are exempt (they win by
   precedence). `braille_engine_set_tables` rejects a colliding mode and
   keeps the previous selection.
8. Space-only, dots-only, and space-plus-dot chords flow through identical
   mask comparisons; nothing branches on individual characters or commands.
9. Defects fixed in the found draft: longer rules were skipped before the
   extendability check, so input never stayed pending; a fresh unmatched
   chord emitted a spurious zero-cell dropped-prefix notice; (test-side)
   factory fixture rules needed disjoint predicates to be a valid table.
10. Commit hooks (`braille_engine_commit_rule`,
    `braille_engine_notify_dropped_prefix`) are weak no-ops; the ordered
    action dispatch and display leaves override them.
