1. Map the core punctuation:

    3. Colon: dots 2, 5.
    4. Exclamation mark: dots 2, 3, 5.
    5. Apostrophe: dot 3.
    6. Hyphen: dots 3, 6.
    7. Period: dots 2, 5, 6.
    8. Question mark: dots 2, 3, 6.
