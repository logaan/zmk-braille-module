# Normative UEB reference

The source of truth is [The Rules of Unified English Braille, Third Edition
2024](https://iceb.org/wp-content/uploads/2025/10/Rules-of-Unified-English-Braille-2024.pdf),
published by the International Council on English Braille (ICEB), edited by
Matthew Horspool. Select uncontracted requirements using sections 2.5 and
5.11; the book covers both grades. A project overview is in the repository's
root [README.md](../README.md).
